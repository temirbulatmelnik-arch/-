# Линия — осанка и фейс-лифтинг

Веб-приложение (PWA) с двумя блоками на главном экране:

- **Фейс-лифтинг** — подбородок, нижний овал, челюсть: прижатие подбородка с сопротивлением (CTAR), язык в нёбо,
  по желанию жевание или сжатие зубов и улыбка с сопротивлением. 4 уровня, 5 дней в неделю по 3–12 минут.
- **Осанка** — ровная шея без дуги вперёд и раскрытые плечи: кивки, подъём головы, «Y–T–W», разворот плеча на боку,
  отжимание «плюс» от стены к полу, «ангел» у стены, растяжки, грудной отдел. 6 уровней, 3 занятия в неделю по 12–28 минут,
  плюс минутные паузы, растяжка между занятиями, прогулка с подсказками и «шея у экрана».

Методика — из отчёта [«Осанка шеи и упражнения для лица»](../tonus/reports/Осанка%20шеи%20и%20упражнения%20для%20лица.md):
переход на уровень после трёх занятий подряд «с запасом», не раньше срока уровня, без боли и со свежей проверкой техники;
внутри уровня удержания и повторы растут ступенями; отдых не короче удержания. Опросники безопасности для шеи (по
руководству APTA) и для челюсти отключают модуль челюсти или предупреждают, что сначала нужен врач.

## Что внутри

- **Плеер**: лента шагов с темпом «вверх — пауза — вниз», сторонами, кругом Y–T–W, удержаниями до отказа
  (кнопка «Не могу держать»), голосом, счётом повторов, тоном, вибрацией и отсчётом последних секунд; перед каждым
  упражнением — 3D-демонстрация и техника.
- **3D-анатомия**: тот же спортсмен 190 см / 90 кг, что в «Тонусе», с костями нижней челюсти и языка. Вид «Мышцы»:
  череп, челюсть, зубы, язык, подъязычная кость, позвонки, лопатки и около сорока мышц лица, шеи и плеч. Работающие
  мышцы светятся тёплым, растягиваемые — голубым, те, что должны молчать, — приглушённым розовым. Фигура ложится на
  спину, живот и бок, встаёт в упор, к стене и в дверной проём, кивает, жуёт и двигает языком.
- **Замеры**: угол шеи и угол плеча по боковому фото (три снимка усредняются), шейно-подбородочный угол по профилю,
  фото анфас, тест выносливости сгибателей шеи, масса и окружность шеи, акромион лёжа. Изменения меньше 5° подписаны
  как погрешность фото. Фото остаются на телефоне миниатюрами.
- **Знания**: шкала доказательности, чего ждать и когда, мифы (с 3D: какую мышцу упражнение нагружает на самом деле),
  образ жизни, безопасность, источники.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # движок программы, статистика, профиль iPhone
npm run build      # dist/; SITE_URL=https://…/linia/ — с готовым профилем linia.mobileconfig
```

3D-модели собирает `tools/build-figure.py` (Python с модулем `bpy`); он берёт тело из сборщика «Тонуса»,
кеш загрузок общий: `python tools/build-figure.py`. Лицензии моделей — `public/figure/LICENSE.txt`
(тело — CC0, анатомия Z-Anatomy / BodyParts3D — CC BY-SA 4.0).

Служебный просмотр одного упражнения в 3D: `/#3d=prone_y` (вид «Мышцы») или `/#3d=prone_y:skin`.

## Публикация

GitHub Actions (`.github/workflows/tonus-pages.yml`) собирает «Тонус» и «Линию» и кладёт «Линию» в подпапку
`linia/` сайта GitHub Pages. Установка на iPhone без App Store — страница `install.html`: «На экран „Домой“» или профиль
конфигурации с одним значком.

Приложение не медицинское изделие и не заменяет консультацию врача.
