# Мой астропрогноз

PWA для iPhone: ежедневный прогноз по полному разбору двух карт (Темирбулат и Дима). Без сервера и внешних API —
все расчёты в браузере, в фоновом потоке (`src/worker.ts`). Адрес: `…github.io/-/astro/`.

## Вкладки

| Вкладка | Что | Файл |
|---|---|---|
| Сегодня | астролябия (небо дня поверх карты), «Главное», шкалы сфер, Луна, транзиты, долгий фон, ретро, контекст | `src/screens/Today.tsx` |
| Мы | фон пары, шкалы пары, как сегодня Дима, композит, даши, синастрия, наложение домов, ведическая совместимость | `src/screens/Us.tsx` |
| Даты | 36 месяцев событий для обоих, фильтры Важное / Я / Дима / Пара | `src/screens/Dates.tsx` |
| Карты | колёса (я, Дима, би-колесо, композит), таблицы, ведика в южноиндийском стиле, сверка расчёта | `src/screens/Charts.tsx` |

## Движок (`src/engine/`)

- `core.ts` — планеты (astronomy-engine, видимые геоцентрические, эклиптика даты), средний узел и средняя Лилит (Меус),
  Хирон по оскулирующим элементам на каждые 2 года (≈±1°), скорость по разнице ±12 ч.
- `houses.ts` — Плацидус (RAMC, истинный наклон, итерация полуподдуг), Вертекс.
- `chart.ts` — данные рождения, натальная карта, Парсы, композит. `aspects.ts` — аспекты и орбисы (натал, транзит, синастрия).
- `transits.ts` — транзиты, сходимость, точность, окно, все проходы одной историей. `moon.ts` — фаза, лунный день, без курса.
- `vedic.ts` — Лахири, накшатры, йоги, караки, Вимшоттари, садэ-сати. `compat.ts` — лунные куты.
- `progress.ts` — прогрессии, солнечные дуги, соляры (Санкт-Петербург), профекции. `events.ts` — «Даты».
- `scores.ts` — шкалы −2…+2. `day.ts` — сборка экранов. `controls.ts` — сверка с контрольными значениями задания.

Толкования — `src/content/interpretations.ts` (планеты, дома, личные заметки к каждой точке обеих карт),
`src/content/pair.ts` (синастрия, композит), `src/content/compose.ts` (сборка без повторов).

## Проверка

```bash
npm ci
npx tsc -p tsconfig.json && npm test   # тест сверяет обе карты, синастрию, ведику, соляры, транзиты и закреплённые даты
npm run build
```

Эталон для сверки — Swiss Ephemeris (файлы seas/sepl/semo_18). Найденные опечатки контрольных значений
(Хирон, Луна/Юпитер/Сатурн Димы, Плутон в 2026–2029) описаны в `controls.ts` и видны во вкладке «Карты → Сверка расчёта».
