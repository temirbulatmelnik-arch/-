# Навыки проекта

Набраны в ноябре 2026 с GitHub для пересборки «Курса»: живо и красиво, но просто и понятно.
У каждого навыка — `SOURCE.md` (откуда, какой коммит) и `LICENSE` (MIT; три навыка для «Астропрогноза» — Apache-2.0).

## Что важнее, если советы расходятся

1. Слова владельца и `kurs/DESIGN.md` (там его решения: сцена «Петербург», закат, градиенты неба, стопка карточек).
2. `CLAUDE.md` проекта: без субагентов — навыки, которые советуют «разослать субагентов», выполняются самостоятельно.
3. Токены и компоненты проекта (`kurs/src/index.css`, `kurs/src/components/motion.tsx`) — навыки их расширяют, а не дублируют.
4. Советы навыков.

Например, `baseline-ui` против градиентов и своих кривых — но небо заката и кривые движения в «Курсе» выбраны владельцем
и навыками Emil Kowalski, поэтому остаются.
