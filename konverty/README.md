# Сортировка конвертов

Приложение для ПК: распознаёт адрес на конверте через веб-камеру и говорит, в какую стопку (район) его положить.

## Что в этой версии

- **Работает без интернета.** Модуль распознавания (Tesseract), русский словарь, модуль Excel и шрифты встроены в файл. Политика безопасности страницы (CSP) запрещает любые сетевые запросы, так что данные не могут уйти с компьютера.
- **Вход по ключу на флешке.** База зашифрована случайным 256-битным ключом (AES-256-GCM). Ключ лежит в файле `Ключ сортировки конвертов.key` на флешке; без него файл не раскрывает ФИО и адреса. Пароль не нужен.
- **Флешку вынули — приложение блокируется** через пару секунд. Также автоблокировка через 5–30 минут бездействия и ручная — Ctrl+L. Блокировка стирает расшифрованную базу из памяти.
- Браузер запоминает, где лежит ключ: при следующих запусках вход — одной кнопкой «Войти по ключу», а если браузер сохранил разрешение — приложение открывается само, как только вставлена флешка.
- **Вход в два шага: ключ, затем файл прогресса** (`Прогресс раскладки.json`, хранится на флешке рядом с ключом). Можно выбрать существующий файл, создать новый или продолжить без файла. Из файла и из браузера берутся более свежие отметки, поэтому старый файл не затрёт новые отметки, а на другом компьютере прогресс подхватывается из файла.
- **Автосохранение в файл прогресса** примерно через секунду после каждой отметки, при блокировке — сразу. В шапке всегда видны кнопка **«Сохранить прогресс»** (Ctrl+S) и время последнего сохранения; если файл не выбран или запись не удалась, кнопка выделяется. В файле только номера записей и время отметок, без ФИО.
- Каждая отметка дополнительно сразу пишется на диск в хранилище браузера, поэтому не теряется даже при внезапном отключении питания.
- **Минимум данных на экране:** по умолчанию фамилия с инициалами и адрес без квартиры (полные данные включаются в настройках).
- **«База Excel с отметками»** (окно «Отчёт по районам»): сохраняет исходный файл базы без изменений — те же лист, строки, столбцы, значения и оформление; у строк разложенных конвертов вся строка таблицы залита жёлтым, у остальных заливки нет. Исходный файл хранится внутри приложения зашифрованным.
- **«Сводка»** — только количество по районам, без ФИО.
- **Новый ключ** (если флешка могла попасть в чужие руки, или для базы из Excel) создаётся в настройках: скачиваются новый ключ и новый файл приложения, старый ключ к нему не подходит. Загруженная из Excel база больше не сохраняется в браузере в открытом виде.
- **«Стереть данные с этого компьютера»** удаляет отметки, журнал и настройки из браузера.
- Пробел запускает сканирование и тогда, когда курсор стоит в пустом поле поиска.
- **Оконные конверты** (наклейка: номер и штрихкод, ФИО заглавными, «улица, д., кв.», город, индекс): штрихкод перед распознаванием закрашивается, а наклон конверта до ±12° выравнивается автоматически. На 48 реальных снимках конвертов прошлых месяцев (два набора по 24, у части снимков наклон 6–8° и смаз): если адресат есть в базе — найден в 192 попытках из 192 (фото, камера крупно, издалека, с наклоном), обычно за полсекунды; на ноябрьской базе, где этих людей нет, — ни одной ложной отметки, в том числе соседей по дому и полного тёзки из другого района.
- Если фамилия с конверта не нашлась в базе ни у кого из похожих, приложение так и пишет: «Фамилия с конверта в базе не найдена — проверьте конверт или найдите адресата вручную». Если в базе нашлись только однофамильцы, а имя и отчество на конверте прочитаны точно и другие, — «Совпала только фамилия: имя и отчество на конверте другие — проверьте конверт»; если совпали фамилия и имя (или отчество), а второе другое, — «ФИО совпадает не полностью: имя или отчество на конверте другое — проверьте конверт».
- **Тёзки.** Если ФИО на конверте совпало с ветераном из базы, но улица другая, а индекс на конверте прочитан и он тоже другой, приложение не отмечает автоматически, а пишет: «ФИО как у ветерана из базы, но адрес на конверте другой — сверьте адрес, прежде чем отмечать». Так конверт тёзки, которого нет в списке, не попадёт в чужой район.

## Сборка

Персональные данные в репозиторий не попадают: база хранится отдельно и подставляется при сборке в зашифрованном виде.

```bash
npm install
node build.mjs --data base.json --xlsx база.xlsx --xlsx-name "База ветеранов.xlsx" --out dist/konverty.html --key dist/ключ.key
```

`base.json` — `{ "districts": [...], "rows": [[индекс_района, фамилия, имя, отчество, индекс, город, нас_пункт, улица, дом, корпус, квартира], ...], "source": "..." }`.

## Проверка движка распознавания

`test/sim.cjs` прогоняет движок сопоставления на тысячах имитаций распознанного текста: именительный и дательный падеж, ошибки распознавания 3–15 %, неполные адреса, отправитель и обращение на конверте, соседи по адресу, полные тёзки, люди не из базы, тёзка не из списка с чужим адресом. Считает: верно / нет решения / засчитан чужой.

```bash
node test/sim.cjs база.json пол.json 300 pos    # «свои» конверты
node test/sim.cjs база.json пол.json 300 neg    # люди не из базы, мусорный текст
node test/sim.cjs база.json пол.json 300 pairs  # соседи по адресу и тёзки
```
