# Курс — личный план выхода из долгов

Веб-приложение (PWA) для iPhone. Держит недельный лимит на жизнь, не даёт пропустить платежи, распределяет премии
по правилам плана и показывает, как уменьшается долг. Ставится на экран «Домой» профилем конфигурации,
как «Тонус» и «Линия»: `…/kurs/install.html`.

## Экраны

Дизайн «Петербург» (`DESIGN.md`): закат над Невой, тёмная тема — поздние сумерки. Шрифты Unbounded (числа, заголовки)
и Geologica. Токены — `src/index.css`, иллюстрация — `src/components/Petersburg.tsx`, календарь с водой и график —
`src/components/MoneyLevel.tsx`, общие компоненты — `src/components/ui.tsx`.

- **Неделя** (`screens/Week.tsx`) — сцена: Дворцовый мост разводится по мере трат (медленно, с постоянной скоростью),
  фонари набережной — дни недели. Сколько можно потратить до понедельника, ≈ в день, резерв (и сколько он должен
  держать до премии), копилка недельных остатков, кнопки «Трата» и «Выписка», «Закрыть неделю» в выходные,
  внимание (платежи ≤ 3 дней, просрочки, сроки чек-листа), ближайшие 7 дней, пауза 48 часов, траты недели.
- **Трата** — сумма → категория → «Записать». Больше 5 000 ₽ — пауза 48 часов. Источник: карта жизни, резерв, кредитка.
- **Платежи** (`screens/Payments.tsx`) — календарь месяца: в каждом дне что уходит и что приходит, день наполняется водой
  по деньгам на карте и в резерве (`dailyTotals` в `domain/cashflow.ts`; меньше 30 000 — вода оранжевая). Под ним
  линия уровня с выводом словами («хватает на весь месяц…»), выбранный день, итоги месяца, лента по датам с фильтрами. Платёж: отметить с фактической суммой,
  поменять сумму и дату (у кредиток они плавают; можно сделать новое число днём платежа каждый месяц).
  Обязательные платежи (`screens/FixedSheet.tsx`) — каждый со своим числом месяца.
- **План** (`screens/Plan.tsx`) — долги с прогнозом и графиком «план и факт», чек-лист из аудита со сроками,
  стратегия: этапы, разделы аудита, правила. Кнопки «Премия» и «Связь с чатом».
- **Бюджет** — траты месяца по категориям против лимитов этапа и «как было до плана», резерв.
- **Этапы** переключаются сами: этап заканчивается, когда закрыты его долги, — лимиты растут.

## Неделя и выписка

В воскресенье — выписка ВТБ за неделю (`screens/Import.tsx`): траты по категориям (дубли с ручными пропускаются),
погашения кредитов и подписки отмечаются оплаченными в календаре, поступления — пришедшими (премия открывает
распределение), исходящий остаток — баланс зарплатной карты для прогноза. Затем «Итог недели» (`screens/WeekSheet.tsx`):
траты против лимита и перевод остатка на отдельный счёт остатков (копилка). Выписку в дни зарплаты загружают так же —
поступления и баланс сразу ложатся в прогноз.

## Связь с чатом «Финансы»

`domain/sync.ts`, `screens/Sync.tsx`:
- **приложение → чат**: отчёт Markdown (долги, оплаты, поступления, итоги недель, категории, чек-лист) — «Поделиться»
  в Claude или добавить в файлы проекта;
- **чат → приложение**: чат по инструкции проекта отвечает блоком JSON `"app": "kurs-plan"` (стратегия, чек-лист,
  правила, этапы, лимиты, решения по премиям, долги, обязательные платежи, точные платежи), приложение показывает
  изменения и применяет их, не трогая траты, отметки, резерв и копилку (`domain/planUpdate.ts`);
- текст инструкции для проекта — там же, кнопка «Скопировать инструкцию».

## Загрузка из банка

1. **Выписка PDF** — с ключом API разбирает Claude, без ключа — pdf.js на телефоне (`domain/pdf.ts`: строки с датой
   и суммой, знак, исходящий остаток), на проверку перед применением.
2. **Скриншоты и PDF → Claude.** Приложение отправляет снимок в API Anthropic с личным ключом пользователя
   (Настройки → «Разбор скриншотов»). Claude определяет, что на экране — список операций, экран кредитки или кредита,
   чек платежа, зачисление, накопительный счёт — и возвращает JSON по схеме (`src/domain/ai.ts`).
   `src/domain/proposals.ts` превращает ответ в список «что обновить»: траты (с поиском дублей), новый остаток долга
   и точный обязательный платёж с датой (заменяет оценку в календаре), отметки оплаты, поступления
   (премия сразу открывает распределение), баланс резерва. Ничего не меняется без «Применить».
3. **Текст со скриншота** — без интернета: iPhone распознаёт текст на фото (Live Text), его вставляют в приложение.
4. **CSV-выписка** — без интернета: столбцы даты, суммы и описания находятся по заголовкам, кодировка UTF-8 или 1251.

Категории по названиям продавцов — `src/domain/categorize.ts` (шаблоны из аудита и русские названия).

## Напоминания

Веб-приложение не может будить телефон по расписанию без сервера, поэтому напоминания — через календарь iPhone:
файл `.ics` с платежами, поступлениями и понедельниками на полгода и будильниками за 3 дня, за день и в день платежа
(Настройки или колокольчик на экране «Платежи»). UID событий стабильные: повторная загрузка обновляет, а не дублирует.
По желанию — цифра на значке приложения (Badging API, после разрешения уведомлений).

## Данные и приватность

- Всё хранится только на телефоне (localStorage); резервная копия — файл JSON (без ключа API).
- Новая редакция плана (`rev` в `seed.enc.json` выше, чем на телефоне) подтягивается при запуске по сохранённому коду
  или после однократного ввода кода; траты, отметки, остатки долгов, резерв и копилка не теряются (`mergeSeed`).
- Личный план из аудита лежит на сайте только зашифрованным: `public/seed.enc.json`, AES-GCM, ключ из кода доступа
  через PBKDF2 (600 000 итераций). Открытый `seed.json` в репозиторий не попадает. Код вводится один раз при первом
  запуске. Правка плана: `npm run unseed -- <код> /tmp/kurs-seed.json` → правка → `npm run seed -- /tmp/kurs-seed.json <код>`.
- Без номеров счетов, карт, договоров и паспортных данных.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # этапы, премии, календарь, прогноз, выписки, .ics, шифрование
npm run build      # dist/; SITE_URL=https://…/kurs/ — с готовым профилем kurs.mobileconfig
```

Публикация — вместе с «Тонусом» и «Линией» (`.github/workflows/tonus-pages.yml`), в подпапку `/kurs/`.
