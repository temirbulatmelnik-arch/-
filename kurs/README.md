# Курс — личный план выхода из долгов

Веб-приложение (PWA) для iPhone. Держит недельный лимит на жизнь, не даёт пропустить платежи, распределяет премии
по правилам плана и показывает, как уменьшается долг. Ставится на экран «Домой» профилем конфигурации,
как «Тонус» и «Линия»: `…/kurs/install.html`.

## Экраны

Дизайн «Петербург» (`DESIGN.md`, раздел «Пересборка ноября 2026»): закат над Невой, тёмная тема — светлые сумерки с луной.
Шрифты Unbounded (числа, заголовки) и Geologica. Токены — `src/index.css`, сцена — `src/components/Petersburg.tsx`,
календарь с водой и линия денег — `src/components/MoneyLevel.tsx`, общие компоненты — `src/components/ui.tsx`,
движения (пружины, цифры-табло `Roll`, свайп строк `SwipeRow`, листание `Pager`) — `src/components/motion.tsx`.

Нижняя панель (`components/TabBar.tsx`) — четыре вкладки по вопросам и «+» посередине: нажатие — записать трату,
удержание — веер «Из банка / Сверка / Чат / Премия». Вкладки уезжают в сторону нажатия, прокрутку каждая помнит своя.
При первом запуске нового вида — знакомство «что где» (`screens/Tour.tsx`), снова — из настроек.

- **Сегодня** (`screens/Week.tsx`) — сцена: при входе мост медленно разводится (около 12 с) вместе с закатом,
  нажатие на сцену разводит заново; «Лахта» вдали, в тёмной теме — луна. Над небом — остаток недели (цифры-табло) и
  стеклянное кольцо дня (`components/DayRing.tsx`, `dayBudget` в `domain/summary.ts`); нажатие на кольцо — траты за
  сегодня (`screens/TodaySheet.tsx`, свайп — изменить, удалить). Фонари набережной — дни недели: нажатие — траты того дня.
  Вдоль набережной можно вести пальцем — подпись дня следует за ним с лёгким щелчком. Потянуть сцену вниз — пролёты
  сводятся вслед за пальцем; отпустили — проверка новой редакции плана и файла из чата (`checkPlan`, `checkInbox` в
  `screens/Sync.tsx`), мост снова разводится (`bridgeControl` в `Petersburg.tsx`). При прокрутке сцена уходит медленнее
  страницы (CSS scroll-timeline), сверху появляется стеклянная полоса с остатком недели и дня.
  Плашка о перерасходе появляется при входе и растворяется. Под сценой — «Из банка», «Сверка», «Чат» и стопка карточек
  как в Wallet (`components/CardStack.tsx`): «Сегодня», «Ближайший платёж», «Дела», «Резерв».
- **Платежи** (`screens/Payments.tsx`) — вывод словами (хватит ли до конца месяца) и три вида, листаются пальцем:
  «Месяц» — календарь с водой по деньгам на карте и в резерве (`dailyLevels` в `domain/cashflow.ts`), линия денег,
  выбранный день; «Хватит ли» — ответ одной фразой и линия резерва до премии, которую ведут пальцем: дата, остаток и
  платёж под пальцем (`components/Coverage.tsx`); если не хватает — не больше двух подсказок; месяцы и узкие места —
  по нажатию; ниже счета по учёту (карта, резерв, кредитка моста, `domain/ledger.ts`), «Сверить с банком»; «Список» — итоги месяца и все платежи по датам
  с фильтрами. Строка платежа сдвигается вправо — «оплачено» (или «снять отметку»), нажатие — лист платежа.
- **Траты** (`screens/Budget.tsx`) — месяц против лимитов этапа: «прилив» из цветов категорий (нажатие — фильтр),
  недели месяца (нажатие — итог недели), категории с полосами, поиск и фильтр по источнику, все траты по дням;
  трата сдвигается влево — изменить или удалить.
- **Долги** (`screens/Plan.tsx`) — общий долг досчитывает вниз от начального, фарватер: долги буями по порядку
  закрытия, судно у текущей цели, гавань «Свобода»; «Пришла премия»; виды «Долги / План / Чек-лист»
  (мост на кредитке, цель, план и факт, карточки долгов; этапы, стратегия, правила; чек-лист аудита).
- **Запись траты** (`screens/AddExpense.tsx`) — своя клавиатура в листе, категории, источник, дата и заметка;
  больше 5 000 ₽ — пауза 48 часов. Сверху — «Из банка».
- **Банк и чат** (`screens/Hub.tsx`) — всё, что приходит снаружи: из банка, сверка, чат «Финансы», премия, счета.
- Листы снизу тянутся пальцем за шапку вниз и закрываются; сообщения выезжают сверху.
- Тактильный щелчок (`components/haptics.ts`) — только в важные моменты: раскрылся веер, свайп дошёл до действия,
  трата записана, страница перелистнута пальцем, день под пальцем на фонарях. На iPhone (iOS 18+) — через
  переключатель `<input switch>`, на Android — Vibration API.
- **Демо-макет**: `VITE_NO_SW=1 VITE_DEMO=1 vite build` — вымышленный план (`src/demo.ts`) без кода и без личных данных.

## Неделя и выписка

В воскресенье — выписка ВТБ за неделю (`screens/Import.tsx`): траты по категориям (дубли с ручными пропускаются),
погашения кредитов и подписки отмечаются оплаченными в календаре, поступления — пришедшими (премия открывает
распределение), исходящий остаток — баланс зарплатной карты для прогноза. Затем «Итог недели» (`screens/WeekSheet.tsx`):
траты против лимита и воскресное пополнение: карту жизни доливают из резерва до лимита следующей недели, остаток недели
остаётся на карте и уменьшает пополнение (`weekReport` в `domain/weekly.ts`). Закрытие недели списывает долитое с
резерва и отмечает пополнение в календаре (`wk:<понедельник следующей недели>`); отметка того же события в «Платежах»
двигает резерв так же, а «Открыть заново» возвращает его (`topUpMove` в `store/store.ts`). Копилка остатков — от старой
схемы, больше не пополняется.

**Воскресная сверка с банком** (`screens/Checkup.tsx`, `domain/ledger.ts`). Приложение ведёт учёт по счетам от
последней сверки: карта жизни (мастер-счёт ВТБ) — плюс пополнения и обычные поступления, минус траты с карты и платежи
«с карты»; резерв — минус платежи «из резерва» и траты из резерва после последнего остатка из банка; кредитка моста —
долг плюс покупки с неё. В воскресенье с 18:00 при входе окно сверки открывается само (и в «Делах» до вторника):
три поля — карта, резерв, долг на кредитке (или «доступно»), под каждым — сошлось или на сколько расходится,
с кнопкой «Добавить трату». Перевод: пополнение по учёту (лимит − остаток недели или план моста) минус поступления,
пришедшие на карту, — одной суммой в нужную сторону. «Перевёл» отмечает пополнение, закрывает неделю и делает остатки
из банка с учётом перевода новой точкой отсчёта; уже отмеченное пополнение второй раз не списывается, а закрытие недели
после резерва из банка (чат, сверка) не вычитает пополнение повторно. Журнал — последние сверки внизу окна и `checkups`
в файле обмена, учёт — `status.ledger`. Прогноз покрытия берёт резерв по учёту. Выписку в дни зарплаты загружают так же — поступления и баланс сразу ложатся в прогноз.

## Связь с чатом «Финансы»

Один файл обмена в обе стороны — JSON `"app": "kurs-exchange"` (`domain/exchange.ts`, окно — `screens/Sync.tsx`):
- **приложение → чат**: «Поделиться файлом» — всё состояние: лимиты (этапы, категории, особые недели, премии),
  долги, обязательные платежи, шаблон поступлений, календарь на 45 дней назад и 75 вперёд с отметками (плюс все дальние
  платежи, где сумма или дата поправлены вручную, — с пометкой `exact`), разовые события,
  траты за 90 дней, резерв, копилка, карта, итоги недель, чек-лист, стратегия; `status` — сводка только для чтения;
- **чат → приложение**: тот же формат, только изменения. Списки с `id`/`key` — «добавить или изменить»,
  удаление — `"delete": true`; `limits.weekly`, `incomes`, `strategy`, `rules` — полным списком. Отметку в `calendar`
  без `key` приложение находит по словам названия, дате (±7 дней) и сумме; не нашло — пишет об этом в просмотре. Приложение показывает
  разницу по разделам с переключателями и применяет выбранное; присланное без изменений ничего не трогает.
  Мост на кредитке (`bridge`, `domain/bridge.ts`): пока резерву не хватает до премии, часть недельных денег — с
  кредитки по плану по неделям; лимит недели тот же, траты `credit` в нём, остаток карты уменьшает кредит следующей
  недели; воскресное пополнение в календаре — по плану моста. Выгрузка: `bridge.used/left`, у недель `spentLife`,
  `spentCredit`, `cardLeft`, `creditLeft`, `left` бывает отрицательным. `"dup": true` — добавить трату, даже если такая
  дата и сумма уже есть.
  Новая трата без `id` с той же датой и суммой, что уже есть в приложении, — повтор, даже под другим названием и категорией
  (как и в выписке); каждая трата приложения закрывает одну строку файла, поэтому две одинаковые поездки остаются двумя.
  Резерв и копилка пишутся в журнал, остатки долгов — в снимок месяца. Старый формат `kurs-plan` тоже читается;
- инструкция для проекта — `domain/sync.ts`, кнопка «Скопировать инструкцию».

## Загрузка из банка

1. **Выписка PDF** — с ключом API разбирает Claude, без ключа — pdf.js на телефоне (`domain/pdf.ts`: строки с датой
   и суммой, знак, исходящий остаток), на проверку перед применением.
2. **Скриншоты и PDF → Claude.** Приложение отправляет снимок в API Anthropic с личным ключом пользователя
   (Настройки → «Разбор скриншотов»). Claude определяет, что на экране — список операций, экран кредитки или кредита,
   чек платежа, зачисление, накопительный счёт — и возвращает JSON по схеме (`src/domain/ai.ts`).
   `src/domain/proposals.ts` превращает ответ в список «что обновить»: траты (с поиском дублей), новый остаток долга
   и точный обязательный платёж с датой (заменяет оценку в календаре), отметки оплаты, поступления
   (премия сразу открывает распределение), баланс резерва. Ничего не меняется без «Применить».
3. **Текст со скриншота** — без интернета: iPhone распознаёт текст на фото (Live Text), его вставляют в приложение.
   Экраны ВТБ «История», Сбера и Т-Банка разбирает `domain/bankText.ts`: заголовки дней с суммой дня, название, сумма и
   категория банка в любом порядке, ошибки распознавания («Іранспорт», «₽» как «ł», «-11.111»), служебные строки и
   уведомления, «Внесите платёж … до …», остатки «Мастер-счёт» и «Резерв». Что делать с каждой операцией — `fromBank`
   в `domain/proposals.ts` по правилам протокола: категория банка → категория плана, переводы людям — «себе или трата»
   (перевод на ту же сумму, что платёж в календаре ±3 дня, отмечает платёж), «Между своими счетами» — резерв ⇄ карта
   (закрывает воскресное пополнение), погашения — отметки, плата банку и переводы с кредитки — не траты, возвраты гасят
   трату, проценты — в резерв, на экране кредитки траты идут с кредитки. Повторы — по отпечатку с порядковым номером
   (две поездки по 95 ₽ — две траты) и по дате и сумме с уже внесёнными (отпечаток привязывается). Если сумма дня в заголовке
   больше видимых операций — «часть дня не видна, пришлите ещё скриншот». Память продавцов (`merchantMemory`,
   Настройки): сменили категорию или нажали «Это я» — запомнится. Применение делает снимок — откат в «Последних импортах».
4. **CSV-выписка** — без интернета: столбцы даты, суммы и описания находятся по заголовкам, кодировка UTF-8 или 1251.

Категории по названиям продавцов — `src/domain/categorize.ts` (шаблоны из аудита и русские названия).

## Напоминания

Веб-приложение не может будить телефон по расписанию без сервера, поэтому напоминания — через календарь iPhone:
файл `.ics` с платежами, поступлениями и воскресными пополнениями карты на полгода и будильниками за 3 дня, за день и в день платежа
(Настройки или колокольчик на экране «Платежи»). UID событий стабильные: повторная загрузка обновляет, а не дублирует.
По желанию — цифра на значке приложения (Badging API, после разрешения уведомлений).

## Данные и приватность

- Всё хранится только на телефоне (localStorage); резервная копия — файл JSON (без ключа API).
- Новая редакция плана (`rev` в `seed.enc.json` выше, чем на телефоне) подтягивается при запуске по сохранённому коду
  или после однократного ввода кода; траты, отметки, остатки долгов, резерв и копилка не теряются (`mergeSeed`).
- Личный план из аудита лежит на сайте только зашифрованным: `public/seed.enc.json`, AES-GCM, ключ из кода доступа
  через PBKDF2 (600 000 итераций). Открытый `seed.json` в репозиторий не попадает. Код вводится один раз при первом
  запуске. Правка плана: `npm run unseed -- <код> /tmp/kurs-seed.json` → правка → `npm run seed -- /tmp/kurs-seed.json <код>`.
- Без номеров счетов, карт, договоров и паспортных данных.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # этапы, премии, календарь, прогноз, выписки, .ics, шифрование
npm run build      # dist/; SITE_URL=https://…/kurs/ — с готовым профилем kurs.mobileconfig
```

Публикация — вместе с «Тонусом» и «Линией» (`.github/workflows/tonus-pages.yml`), в подпапку `/kurs/`.
