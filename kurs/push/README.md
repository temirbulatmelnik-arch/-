# Отправитель напоминаний «Курса»

Node.js 24, SQLite на постоянном диске и HTTPS на стороне хостинга. Развёртывается
отдельно от GitHub Pages. Перед эксплуатацией назначьте конкретного владельца сервера.

1. Выполните `npm ci` и `npm test` в этой папке.
2. Сгенерируйте VAPID-пару командой `./node_modules/.bin/web-push generate-vapid-keys`.
3. Установите переменные `KURS_ORIGIN`, `VAPID_CONTACT` (mailto), `VAPID_PUBLIC_KEY`,
   `VAPID_PRIVATE_KEY`, `DATABASE` (файл на защищённом постоянном диске). Разрешите
   приложению обращаться к этому origin через HTTPS. Закрытый ключ храните у провайдера.
4. Запустите `npm start` одним процессом с автоперезапуском. Ставьте за HTTPS-прокси,
   который ограничивает частоту запросов и не пишет тела и токены в журналы.
   Слушатель по умолчанию 127.0.0.1:8787, настраивается через HOST и PORT.
5. Подайте публичный адрес с путём /push и открытый VAPID-ключ в сборку «Курса»
   через `VITE_KURS_PUSH_ENDPOINT` и `VITE_KURS_PUSH_VAPID_PUBLIC_KEY`.

Отправитель хранит только подписку устройства, хеш токена и непрозрачные
идентификаторы с расписанием UTC. Он не принимает финансовый JSON и очищает
отозванные и устаревшие подписки. Состояние расписания заменяется целиком,
что позволяет отменять напоминания. Каждая установка подписывается отдельно.
Системная служба push может задержать доставку и после принятия сообщения
провайдером его уже нельзя отозвать. Используется короткий TTL.

Пройдите тест на физическом iPhone с установленным PWA и подтверждённым
разрешением, включая тест в фоне, смену даты, оплату, отмену и отключение.
До подключения рабочего HTTPS-отправителя «Курс» использует Календарь iPhone.
