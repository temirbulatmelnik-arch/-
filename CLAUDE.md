# Репозиторий: личные веб-приложения для iPhone

Владелец работает только с iPhone. Всё общение и интерфейс — на русском.

| Папка | Что это |
|---|---|
| `tonus/` | «Тонус» — тренер мышц тазового дна (корень сайта) |
| `linia/` | «Линия» — осанка и фейс-лифтинг (`/linia/`) |
| `kurs/` | «Курс» — личный план выхода из долгов (`/kurs/`) |
| `konverty/` | отдельный инструмент, к сайту не относится |

Каждое приложение — Vite + React + TypeScript + Tailwind 4 + zustand, PWA. Ставится на iPhone профилем Web Clip
(`src/install/`). Подробности — в README каждой папки; читать его, а не обходить весь код.

## Команды (из папки приложения)

```bash
npm ci
npx tsc -p tsconfig.json && npm test   # проверка перед коммитом
npm run build                          # сборка; превью: npx vite preview
```

## «Курс»: приватность — репозиторий публичный

- Личные цифры (долги, доходы, лимиты этапов, решения по премиям) — только в зашифрованном `kurs/public/seed.enc.json`.
  В коде, тестах, README и коммитах — никаких реальных сумм, названий своих долгов и кода доступа.
- Править план: код спросить у владельца →
  `node tools/decrypt-seed.mjs <код> /tmp/kurs-seed.json` → правка → `node tools/encrypt-seed.mjs /tmp/kurs-seed.json <код>` →
  удалить открытый файл. Тот же код, чтобы владельцу не вводить новый.
- Структура плана — `PlanSeed` в `kurs/src/domain/types.ts`, `PlanConfig` и `bonusRules` — в `kurs/src/domain/plan.ts`.
- План уже на телефоне не обновляется сам: после изменения плана владелец делает «Стереть все данные» и вводит код заново
  (или нужно добавить миграцию).

## Как работать экономно

- Без субагентов; читать только нужные файлы (README → нужный модуль).
- Проверка: `tsc` + `npm test` + `npm run build`. Скриншоты в Playwright — только когда меняется внешний вид,
  Chromium уже установлен (`/opt/pw-browsers`, пакет `playwright` в глобальных модулях).
- Новая задача — новая сессия: этой памятки достаточно, историю прошлых чатов перечитывать не нужно.
